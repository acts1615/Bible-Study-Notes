# 성경연구노트

성경 본문을 여러 번역으로 나란히 읽고, 구절마다 연구 메모를 붙여 두는 **개인 연구용 웹 도구**입니다.
설치 없이 브라우저에서 열 수 있고, 앱처럼 설치해 쓸 수도 있습니다.

## 할 수 있는 일
- **번역 비교** — 여러 번역을 한 화면에 나란히(또는 아래로) 놓고 읽습니다. 카톨릭 성경처럼 장절 구분이 다른 번역도 번호를 억지로 맞추지 않고 따로 보여 줍니다.
- **구절 메모** — 내 컴퓨터의 노트 폴더(Obsidian 형식 md)를 연결하면 구절마다 메모를 달고 고칠 수 있습니다. 메모에 적은 성경 구절은 자동으로 링크가 되고, 그 구절 쪽에서는 백링크로 다시 보입니다.
- **빠른 이동** — 상단의 `성경 › 신약 › 로마서` 경로로 책·장 목록으로 바로 갑니다. 마지막으로 읽던 곳과 입력 중이던 메모도 새로고침 뒤 그대로 돌아옵니다.
- **앱처럼 설치** — 크롬·엣지의 설치 기능으로 바탕화면 아이콘으로 엽니다.

## 시작하기
1. 배포된 주소를 열면 개역한글이 바로 보입니다.
2. 번역을 늘리려면 왼쪽 메뉴의 **＋ 번역 파일 추가** 또는 **📂 폴더째 추가**를 쓰세요. (`.json`, `.txt`, `.js`)
3. 메모를 쓰려면 같은 메뉴에서 노트 폴더를 연결하세요. (폴더 연결은 PC의 크롬·엣지)

## 개인 정보
메모와 노트는 서버로 보내지 않고 사용자의 컴퓨터 폴더와 브라우저에만 저장됩니다. 이 저장소에는 프로그램과 저작권이 만료된 개역한글만 들어 있습니다.

---
아래는 번역 파일 형식과 배포 방법 등 만든 사람을 위한 기록입니다.

## 번역
- 기본 내장: **개역한글** (저작권이 만료된 공개 번역)
- 다른 번역: 화면 왼쪽 **＋ 번역 추가**에서 내가 가진 번역 파일을 선택하면 됩니다. 폴더를 연결한 경우 폴더의 `translations/`에, 아니면 이 브라우저에만 저장됩니다.
- 이 저장소에는 개역한글 외 번역을 올리지 않습니다 (`.gitignore`가 막습니다).

## 번역 파일 형식 (`translations/<id>.json`)
```json
{ "id":"nkrv", "name":"개역개정", "abbr":"개역개정", "lang":"ko",
  "versification":"a", "books": { "0": { "1": { "1": "본문…" } } } }
```
`books`는 `{책번호(0=창세기 … 65=요한계시록): {장: {절: 본문}}}` 입니다.
`versification`이 `catholic`이거나 장의 절 수가 기준 번역과 다르면, 번호를 억지로 맞추지 않고 따로 보여 줍니다.
`const BIBLE_X = {"창세기":{...}}` 형태의 파일도 66권이면 그대로 추가할 수 있습니다.

## 배포
`main`에 올리면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다.
(저장소 Settings → Pages → Source 를 **GitHub Actions**로 한 번 지정)

## 출처
개역한글 본문: 대한성서공회 (저작권 보호기간 만료). 자세한 내용은 THIRD_PARTY.md.

## 버전 표시
화면 왼쪽 위에 `ver 1.0.a.1` 처럼 표시됩니다. 올릴 때마다 `node tools/bump.js` 를 실행하면 맨 뒤 숫자부터 올라갑니다.
(숫자 1-9 → 9 다음은 알파벳 a→b, 숫자는 1로 / z 다음은 앞자리가 올라감)

## 앱으로 설치 (PWA)
Pages 주소(https)에서 크롬/엣지로 열면 왼쪽 메뉴에 **⬇ 앱으로 설치** 버튼이 나타납니다.
설치하면 바탕화면·시작 메뉴 아이콘으로 열리고, 인터넷이 없어도 개역한글 보기가 됩니다.
노트 폴더를 연결할 때 브라우저가 묻는 허용 창에서 **"방문할 때마다 허용"**을 고르면 다음부터 다시 묻지 않을 수 있습니다.
`node tools/bump.js` 는 화면 버전과 `sw.js` 의 캐시 버전을 함께 올립니다.
